# Games Discord Bot

بوت ألعاب Discord بـ Node.js و discord.js مع فصل واضح بين الألعاب الفردية والفعاليات الجماعية.

## النظام

### الألعاب الفردية
تبدأ بالنقطة `.` ومتاحة لجميع أعضاء السيرفر. لا تمنح أي نقاط ولا تدخل في ترتيب الفعاليات.

أمثلة:

```text
.اسرع
.اعلام
.زر
.فكك
.ادمج
.اعكس
.حرف
.صحح
.ترتيب
.الوان
.ايموجي
.اكشف
```

### الفعاليات الجماعية
تبدأ بالشرطة `-`، ولا يمكن إنشاؤها إلا من الإدارة أو رتبة رئيس الفعاليات المحددة في إعدادات السيرفر.

أمثلة:

```text
-مافيا
-روليت
-xo
-كراسي
-حجرة
-نرد
-غميضة
-ريبلكا
-دولة
-رسمة
-كلمة
```

الفعاليات الجماعية فقط هي التي تمنح النقاط. الافتراضي هو **10 نقاط لكل فائز**، ويمكن للإدارة تغييره من إعدادات السيرفر.

`-روليت` هنا عجلة ترفيهية عشوائية بدون رهانات أو عملات.

## الإدارة

```text
-توقيف
```

يوقف اللعبة أو الفعالية الحالية في القناة، ومتاح للإدارة أو رئيس الفعاليات.

```text
/إعدادات-الألعاب
```

الإدارة تستطيع ضبط:

- رتبة رئيس الفعاليات.
- نقاط الفائز من 1 إلى 50.
- الحد الأقصى للاعبين من 2 إلى 20.
- مدة الـLobby من 10 إلى 120 ثانية.

الإعدادات محفوظة حسب `guild_id`، لذلك كل سيرفر عنده إعداداته ونقاطه وترتيبه بشكل مستقل.

## الإحصائيات

```text
/نقاطي
/ترتيب-الألعاب
```

الإحصائيات محفوظة في SQLite ومربوطة بالسيرفر والعضو.

## التشغيل

1. انسخ `.env.example` إلى `.env`.
2. ضع `DISCORD_TOKEN` و `CLIENT_ID`، ومع `GUILD_ID` إذا كنت تريد تسجيل أوامر مباشرة على سيرفر محدد.
3. ثبت الحزم:

```bash
npm install
```

4. شغل البوت:

```bash
npm start
```

يحتاج المشروع Node.js 20 أو أحدث.
