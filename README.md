# Games Discord Bot

بوت ألعاب Discord بـ Node.js و discord.js مع فصل واضح بين الألعاب الفردية والفعاليات الجماعية.

## النظام

### الألعاب الفردية
تبدأ بالنقطة `.` ومتاحة لجميع أعضاء السيرفر. لا تمنح أي نقاط ولا تدخل في ترتيب الفعاليات.

أمثلة:

```text
.اسرع
.اعلام
.زر
.فكك
.ادمج
.اعكس
.حرف
.صحح
.ترتيب
.الوان
.ايموجي
.اكشف
```

### الفعاليات الجماعية
تبدأ بالشرطة `-`، ولا يمكن إنشاؤها إلا من الإدارة أو رتبة رئيس الفعاليات المحددة في إعدادات السيرفر.

أمثلة:

```text
-مافيا
-روليت
-xo
-كراسي
-حجرة
-نرد
-غميضة
-سباق
-ريبلكا
-دولة
-رسمة
-كلمة
```

### التصويت على الفعاليات

```text
-تصويت
```

يفتح تصويتاً منظماً على الألعاب الجماعية، وكل عضو مخول للتصويت يختار مرة واحدة، ثم تبدأ اللعبة الفائزة تلقائياً.

الفعاليات الجماعية فقط هي التي تمنح النقاط. الافتراضي هو **10 نقاط لكل فائز**، ويمكن للإدارة تغييره من إعدادات السيرفر.

`-روليت` هنا عجلة ترفيهية عشوائية بدون رهانات أو عملات.

## الإدارة

```text
-توقيف
```

يوقف اللعبة أو الفعالية الحالية في القناة، ومتاح للإدارة أو رئيس الفعاليات.

```text
/إعدادات-الألعاب
/إضافة-روم-ألعاب
/إزالة-روم-ألعاب
/رومات-الألعاب
```

الإدارة تستطيع ضبط:

- رتبة رئيس الفعاليات.
- نقاط الفائز من 1 إلى 50.
- الحد الأقصى للاعبين من 2 إلى 20.
- مدة الـLobby من 10 إلى 120 ثانية.

الإعدادات محفوظة حسب `guild_id`، لذلك كل سيرفر عنده إعداداته ونقاطه وترتيبه بشكل مستقل.

## الإحصائيات

```text
/نقاطي
/ترتيب-الألعاب
```

الإحصائيات محفوظة في SQLite ومربوطة بالسيرفر والعضو.

## التشغيل

1. انسخ `.env.example` إلى `.env`.
2. ضع `DISCORD_TOKEN` و `CLIENT_ID`، ومع `GUILD_ID` إذا كنت تريد تسجيل أوامر مباشرة على سيرفر محدد.
3. ثبت الحزم:

```bash
npm install
```

4. شغل البوت:

```bash
npm start
```

يحتاج المشروع Node.js 20 أو أحدث.

## فصل الأنظمة

هذا المستودع هو المكان المركزي لأنظمة الألعاب التي كانت موزعة داخل مشروع Nawaf. تم توحيد الألعاب الفردية والجماعية، السباق، نظام التصويت، رومات الفعاليات، إعدادات روم الألعاب الفردية، الإحصائيات، والنقاط داخل هذا المشروع.

### أوامر فردية مدعومة

```text
.زر  .اسرع  .فكك  .ادمج  .اعلام  .اعكس  .حرف  .صحح  .ترتيب  .الوان  .إيموجي  .اكشف
```

وتوجد كذلك aliases قديمة من نظام Nawaf مثل `-زر` و`-اسرع` و`-فكك` و`-ادمج` و`-اعلام` وغيرها للتوافق.


## الألعاب المضافة من تصميم المشروع

### فعاليات جماعية
- `-بومب` أو `-لغم`: بومب/لغم مع خروج عشوائي للاعبين وملصق خروج عشوائي.
- `-وصل`: Connect Four بين لاعبين.
- `-لغز`: فعالية ألغاز سريعة.

### الألعاب الفردية
- `.حروف`
- `.جماد`
- `.كلمة`
- `.اشبك`
- `.عواصم`
- `.مفرد`
- `.جمع`
- `.رقم`
- `.حساب`

الأمر `/لعب` أصبح يدعم البحث التلقائي داخل الكتالوج الكامل بدلاً من حصره في 25 اختياراً ثابتاً.

### التصويت
`-تصويت` أصبح بتصميم قائمة الألعاب الجماعية الموجودة في الملف المرجعي، ومدته دقيقة كاملة.

### ملصقات الخروج
تمت إضافة 13 ملصق خروج إلى `assets/elimination-stickers`، ويتم اختيار ملصق عشوائي عند خروج لاعب في الألعاب التي تعتمد الإقصاء.
